# ❤️ Heart Disease Prediction

A Machine Learning based web application that predicts the risk of heart disease using patient health parameters.

### 🛠️ Tech Stack

Python • Flask • Scikit-learn • Pandas • SQLite • HTML • CSS • JavaScript

### 🤖 Machine Learning

* Algorithm: Random Forest Classifier
* Dataset: Heart Disease Dataset
* Model saved using Joblib

### ✨ Features

* Heart disease risk prediction
* BMI Calculator
* Prediction History
* Patient Records
* Health Analytics
* PDF Report Generation
* Health Tips & Weather
* User Authentication

### 🎯 Objective

To build an easy-to-use web application that demonstrates the practical use of Machine Learning for preliminary heart disease risk assessment.

**Note:** This project is developed for educational purposes and is not a substitute for professional medical diagnosis.
